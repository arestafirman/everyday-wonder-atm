A one-sentence entry for Everyday Wonder: an ATM hands over a banknote with a phone number written on it, and the rest of the day is spent wondering whose emergency it was.

`main.ts` writes the sentence deterministically to `/output/entry.txt` (or `$OUTPUT_DIR` when set), with no trailing newline. No network, no randomness, no dependencies.

Why this angle: cash is a physical object that carries a stranger's trace — a handwritten number passed from one person's pocket to another's — where the field is saturated with kettles, lifts, taps, and shadows. The two beats land in one read: the setup (an ATM dispensing a marked banknote) and the literal consequence (a whole day spent wondering whose emergency that number belonged to).
